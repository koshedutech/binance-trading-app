## Key Insights & Lessons Learned

### 1. Mode → Strategy Architecture
The correct hierarchy is Mode → Strategy (not Strategy → Mode). User selects a Mode (trading style), and each mode contains 4 strategies.

### 2. Settings Lifecycle Rule
Any new user-configurable setting MUST follow the complete lifecycle:
```
default-settings.json → Database → Redis Cache → API → Frontend
```

### 3. Additive Scoring System
- 55-point minimum threshold for entry
- Score breakdown: Technical (40), Context (30), LLM (20), History (10)
- Confidence tiers: 55-74 (minimum), 75-84 (high), 85+ (ultra)

### 4. 16 Independent Configurations
Each Mode+Strategy combination has completely independent settings:
- 4 Modes: Scalp, Swing, Position, Ultra_Fast
- 4 Strategies: Trend Following, Mean Reversion, Breakout, Range Trading
- Total: 16 unique configurations per user
